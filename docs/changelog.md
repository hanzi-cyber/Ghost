# 变更记录

## [1.0.0] - 2026-09-06

### 新增

#### 项目结构
- 新增 `docs/` 目录，包含实验文档（基线、架构、变更记录）
- 新增 `theme/oss-blog-theme/` 目录，自定义主题源码
- 新增 `tests/` 目录，验收测试用例
- 新增 `runtime/` 目录，Ghost 本地运行实例（不提交 Git）
- 更新 `.gitignore`，添加 `runtime/` 目录忽略规则

#### 自定义主题
- 基于 Ghost Source 主题 v1.7.2 创建自定义主题 `oss-blog-theme` v1.0.0
- 修改 `package.json`：主题名称、版本号、描述信息
- 修改 `default.hbs`：添加自定义 CSS 和 JavaScript 资源引用
- 修改 `post.hbs`：增强相关文章推荐功能，按标签智能匹配

#### 自主扩展功能
- **相关文章推荐**：按当前文章主标签筛选相关文章，支持降级到最新文章
- **搜索关键词高亮**：从 URL 参数获取搜索词，在文章内容中高亮匹配关键词
- **阅读进度条**：页面顶部显示阅读进度，随滚动动态更新
- **返回顶部按钮**：滚动超过 300px 时显示，点击平滑返回顶部
- **文章卡片悬停效果**：鼠标悬停时卡片上浮并显示阴影
- **标签样式美化**：文章标签使用渐变背景和圆角样式

#### 样式文件
- 新增 `assets/css/oss-custom.css`：包含所有自定义样式
  - 相关推荐区域样式
  - 搜索高亮样式
  - 阅读进度条样式
  - 返回顶部按钮样式
  - 文章卡片悬停效果
  - 标签样式美化
  - 响应式布局调整
  - 无结果提示样式

#### 脚本文件
- 新增 `assets/js/oss-custom.js`：包含所有自定义脚本
  - 阅读进度条初始化与更新
  - 返回顶部按钮显示/隐藏与点击事件
  - 搜索关键词高亮（支持多关键词、忽略大小写）
  - 搜索结果页无结果提示
  - 文章卡片增强（预留扩展接口）

#### 文档
- 新增 `docs/baseline.md`：实验基线文档（环境版本、账号信息、目录结构）
- 新增 `docs/architecture.md`：项目架构说明（整体架构、修改边界、功能实现）
- 新增 `docs/changelog.md`：变更记录（本文档）

### 配置

#### Ghost 实例配置
- 安装 Ghost 6.59.0 本地实例
- 配置 SQLite 数据库
- 启用会员功能（公开注册）
- 启用评论功能（所有会员可评论）
- 设置博客标题为"开源个人博客"

#### 演示数据
- 创建 4 个标签：News、技术分享、开源软件、学习笔记
- 发布 2 篇实验文章（含默认文章共 3 篇）
- 创建 1 个测试会员账号：member@example.com
- 创建管理员账号：admin@example.com
