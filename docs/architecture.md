## 修改边界说明

### 允许修改的目录

| 目录 | 说明 |
|---|---|
| `theme/oss-blog-theme/` | 自定义主题源码，包含模板、样式和脚本 |
| `docs/` | 实验文档，包括基线、架构、变更记录 |
| `tests/` | 测试用例文档 |
| `README.md` | 项目说明文档 |
| `NOTICE.md` | 第三方资源许可证声明 |
| `.gitignore` | Git 忽略规则（添加 runtime/ 目录） |

### 禁止修改的目录

| 目录 | 说明 |
|---|---|
| `runtime/` | Ghost 运行实例，包含核心代码和数据，不提交 Git |
| `ghost/` | Ghost 源码核心模块 |
| `apps/` | Ghost 前端应用（Admin、Portal、Comments 等） |
| `packages/` | Ghost 内部依赖包 |
| `node_modules/` | 依赖包 |

## 自主扩展功能实现

### 1. 相关文章推荐（按标签匹配）

**实现位置**：`post.hbs`

**实现方式**：使用 Ghost `{{#get}}` 助手，按当前文章的主标签筛选相关文章。

```handlebars
{{#get "posts" include="authors,tags" 
    filter="tags:[{{post.primary_tag.slug}}]+id:-{{post.id}}" 
    limit="3" as |related_by_tag|}}
```

**降级方案**：如果同标签文章不足 3 篇，回退到显示最新文章。

### 2. 搜索关键词高亮

**实现位置**：`assets/js/oss-custom.js`

**实现方式**：从 URL 参数 `q`/`keyword`/`query` 获取搜索词，遍历文章内容文本节点，用 `<mark>` 标签高亮匹配关键词。

### 3. 阅读进度条

**实现位置**：`assets/js/oss-custom.js` + `assets/css/oss-custom.css`

**实现方式**：监听页面滚动事件，计算当前阅读进度百分比，动态更新顶部进度条宽度。

### 4. 返回顶部按钮

**实现位置**：`assets/js/oss-custom.js` + `assets/css/oss-custom.css`

**实现方式**：滚动超过 300px 时显示按钮，点击后平滑滚动到页面顶部。

## 数据流

### 文章发布流程

1. 管理员在 Ghost Admin 中编辑文章
2. 文章数据保存到 SQLite 数据库
3. 前台通过 Content API 获取文章数据
4. 自定义主题模板渲染文章页面
5. 自定义 JS 添加阅读进度条和返回顶部功能

### 相关推荐流程

1. 访问文章详情页
2. `post.hbs` 模板通过 `{{#get}}` 查询同标签文章
3. Ghost Content API 从数据库查询相关文章
4. 模板渲染相关推荐区域
5. 自定义 CSS 美化推荐区域样式
